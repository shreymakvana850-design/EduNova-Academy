EduNova Academy — Static Website

Files:
- index.html: Complete responsive website in one file.

Technology:
- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is required for Bootstrap and Google Fonts CDN resources.

Before publishing:
1. Replace your-email@example.com, +91 XXXXX XXXXX, and the sample address.
2. Replace 919999999999 in BOTH WhatsApp URLs with the academy's WhatsApp number (country code + number, digits only).
3. Update the course names and descriptions to match the academy.
4. The enquiry form opens a prefilled WhatsApp message; it does not store submissions or send emails.
